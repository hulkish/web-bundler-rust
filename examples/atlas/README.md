# Atlas

A large fixture for `webbundler --threads`. The sources are generated by `generate.py` so the layout stays regular. Open any file: the first comment says which entry owns it and why the bundler keeps it in `chunk.js` or in that entry.

## Layout

```
src/entries/     one entry per desk: catalog, warehouse, storefront, dispatch, archive, ledger
src/shared/      imported by every entry through boot.js, so these modules go in chunk.js
src/bridges/     each file is imported by exactly two entries, so it is shared too
src/areas/       modules private to one entry; they stay in that entry's output
src/lazy/        panels loaded with import("./panel-nn.js") from that area's loader
src/styles/      26 stylesheets, imported from src/shared/styles.js
src/icons/       svg and png icons referenced from those stylesheets
```

`src/shared/boot.js` is the shared index. `src/areas/<desk>/index.js` is that desk's barrel. `src/areas/<desk>/loader.js` is the dynamic-import list.

## What the code exercises

- Constant folding, `JSON.parse`, `Array.of`, `Math.*` (except `Math.random`), templates, dead branches, and anonymous function expressions. A few lanes shadow `Math` or contain `eval` so those folds must stay put.
- `process.env.NODE_ENV` and `ATLAS_LANES` come from `define` in the config.
- A handful of `.jsx` modules lower JSX before the rest of the pipeline.
- `src/shared/mod-000.js` and `mod-001.js` import each other.
- Fifty-six npm packages are imported and listed in `external`. They are not installed; the bundle leaves them for the runtime.
- Stylesheets point at icons with `url(...)`. The bundler copies those images and rewrites the urls. `sheet-00.css` also has a remote url, a `data:` url, and a missing file, which stay as written.

## Bundle

From the repository root:

```bash
cargo run --release -- --threads 8 --config examples/atlas/webbundler.config.json
```

Omit `--threads` to build on one thread. The output is `examples/atlas/dist/`: `chunk.js`, one file per entry, `bundle.css`, and the copied icons.

`--optimize` and `--minify` are off here. Turn them on when you want the folds in these files to run:

```bash
cargo run --release -- --threads 8 --optimize --minify --config examples/atlas/webbundler.config.json
```

Regenerate the tree with `python3 examples/atlas/generate.py`. Counts and sizes are in `MANIFEST.json`.
